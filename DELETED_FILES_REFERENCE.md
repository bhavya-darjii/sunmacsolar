## How to Recover Any File

```bash
# See any deleted file's content
git show <commit-before-deletion>:<path/to/file>

# Restore a single file back to disk
git checkout <commit-before-deletion> -- <path/to/file>

# Example: restore the original PRD
git checkout bbe462e -- memory/PRD.md
```

> **Note:** The commit just before deletion is **`bbe462e`** — use that commit hash as your restore point for all files listed here.
